

# Karnataka Through Time 🇮🇳

An immersive Karnataka Rajyotsava website celebrating the state's history,
heritage, culture, innovation and future.

## Features

- Animated 3D cosmic hero built with Three.js
- Interactive timeline with eight historical eras
- Heritage cards and culture highlights
- Rajyotsava celebration finale
- Responsive mobile and desktop layouts
- Scroll progress indicator
- Mobile navigation
- No backend or API key required

## Technology

- HTML5
- CSS3
- JavaScript ES modules
- Three.js

## Run locally

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

Alternatively, with Python installed, run this command inside the project folder:

    python -m http.server 5500

Then open `http://localhost:5500` in your browser.

Because Three.js is loaded as an ES module, run the project through a local
web server rather than opening the HTML file directly.

## Deploy using GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to its root.
3. Open repository Settings.
4. Select Pages.
5. Choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for deployment.

## Important notes

- An internet connection is required for the Three.js CDN, Google Fonts,
  and remote heritage images.
- The 3D planet, rings and particles are decorative simulations, not a
  scientific astronomical model.
- Heritage images are illustrative placeholders. Verify the actual subject,
  image licence and attribution before public or commercial use.
- Historical dates are approximate and should be fact-checked before
  educational or formal publication.
- This project does not currently use a verified Karnataka boundary map.
